# Animei 

**动漫电影记录年历** — 像 GitHub 贡献图一样，用色彩标记你观看动漫/电影的每一天。

##  功能

- **年历网格** — 7×53 周网格视图，一年尽收眼底
- **月份视图** — 按月布局的日历，竖屏手机自动切换
- **多年度滚动** — 连续滚动浏览多年，专注模式只聚焦当前年份
- **笔刷上色** — 拖拽或点击为日期上色，支持覆盖/添加两种模式
- **16 种调色板** — Office、樱花、赛博朋克、莫兰迪、复古…一键切换
- **撤销/重做** — Ctrl+Z / Ctrl+Shift+Z，最多保留 100 步
- **键盘快捷键** — `B` 笔刷 / `S` 设置 / `1-9` `0` `-` `=` 选色
- **中英文切换** — 内置中文与英文
- **本地存储** — 所有数据保存在浏览器 localStorage，不丢失

##  技术栈

Vue 3 + Vite + pnpm，纯手写组件，无 UI 库依赖。

##  快速开始

### 1. 下载本项目的两种方式

**方式 A — Git 克隆（推荐，方便后续更新）**
```bash
git clone <仓库地址>
cd animei
```

**方式 B — 下载 ZIP（适合只使用一次）**
- 打开本项目 GitHub 页面，点击绿色 `<> Code` 按钮 → **Download ZIP**
- 下载后**解压到一个永久位置**（比如 `D:\animei`），解压后不要移动文件夹
- ⚠️ 切记：你的上色记录保存在浏览器的 localStorage 中，如果移动或删除文件夹，之前的数据不会丢（数据在浏览器里，不在文件夹里）
- 以后想更新新版本，需要重新下载 ZIP 覆盖，但注意备份 localStorage 数据

### 2. 安装 Node.js

前往 https://nodejs.org/ 下载 **LTS 版本**（长期支持版），安装时一路点"下一步"即可。

安装完成后，打开终端（cmd / PowerShell）验证：
```bash
node --version   # 能看到版本号就说明装好了
```

### 3. 安装 pnpm

在终端中执行：
```bash
npm install -g pnpm
```

验证：
```bash
pnpm --version   # 能看到版本号就行
```

### 4. 安装依赖 & 启动

在项目文件夹里打开终端，执行：
```bash
pnpm install
pnpm dev
```

浏览器会自动打开 http://localhost:3000，开始上色吧！ 🎉

> 💡 以后每次使用时，在项目文件夹打开终端，只需执行 `pnpm dev` 即可启动，不需要重复 `pnpm install`。

### 构建部署

```bash
pnpm build      # 产物输出到 dist/
pnpm preview    # 本地预览构建结果
```

##  数据说明

数据全部存储在**浏览器 localStorage** 中，不依赖任何服务器和账号。清除浏览器数据会导致记录丢失，建议定期备份。
